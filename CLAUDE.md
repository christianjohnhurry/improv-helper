# Project guidelines

## Commits

- Do not add a `Co-Authored-By` line (or any other Claude attribution) to commit messages.
- Commit at logical points throughout a session, once each coherent unit of work is complete and tests pass. Do not save all changes for a single commit at the end.
- Write sensible commit messages in standard technical English: a concise imperative subject line (e.g. "Add timestamp validation"), followed by a body explaining what and why when the change is not obvious.
